# art

Small generative art toys that run in the browser, from [art.sala.company](https://art.sala.company).

## Artograph

[`index.html`](index.html) is Artograph, a gear-and-pen drawing toy in the spirit of the classic Spirograph. It has rings and wheels with real tooth counts, pen holes, gel-pen colors, adjustable speed, rosettes, PNG/SVG export and share links. Open the file in any browser; nothing needs to be installed.

Play it at https://art.sala.company
