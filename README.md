# art

Small generative art toys that run in the browser, from art.sala.company.

## Artograph

[`artograph/index.html`](artograph/index.html) is a gear-and-pen drawing toy in the spirit of the classic Spirograph. It has rings and wheels with real tooth counts, pen holes, gel-pen colors, adjustable speed and stacked layers. Open the file in any browser; nothing needs to be installed.

Play it at https://jamalxcode.github.io/art/artograph/
